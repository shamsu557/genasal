GENASAL NIGERIA LIMITED — CLICKABLE INTERFACE PROTOTYPE
Website: gnsl.com.ng (this archive is NOT deployed to that domain)

QUICK START
1. Extract the ZIP.
2. Open index.html in Chrome, Edge, Safari or Firefox.
3. Use the sidebar to choose among 48 interface links grouped by role/feature.
4. Click "All boards" for a gallery of all 10 presentation boards.
5. Use the arrows, Fit, +/- zoom and presentation button to explore.
6. Copy link gives a direct link to the chosen screen in the prototype.

PUBLISH ON CPANEL
- Create a subfolder such as public_html/prototype/ on your hosting.
- Upload the CONTENTS of the extracted folder to that directory.
- Visit https://gnsl.com.ng/prototype/ (only after you publish it yourself).
- Then links you copy from the prototype are shareable with others.
- Add access protection if it is an internal prototype.

WHAT THIS IS
A clickable, navigable Figma-style gallery of the existing GENASAL UI IMAGE boards.
Each board contains multiple illustrated desktop/mobile mockups.
The sidebar links open the correct BOARD, not an independently coded functional page.
The forms, payments, role switching, tracking and staff administration in the images
are illustrations. No database, Paystack, SMS gateway, real login or backend is wired up.
Screens absent from the image boards are NOT presented as fully designed screens.

NOTE
Some image-generated text, example figures and dates may be inaccurate or illustrative.
Validate against the final SRS before coding the actual product.
